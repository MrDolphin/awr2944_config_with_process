# AWR2944P 船载海面仿真 V0.1 设计

## 目标

交付一个可手动验收、可复现的平面海面仿真闭环，用于回答安装高度和固定俯角如何改变 AWR2944PEVM 原厂天线对海面的照射范围。V0.1 只计算几何、天线方向图和单位归一化散射系数下的相对接收功率，不声称得到已由实测校准的绝对海杂波功率。

## 范围

包含：

- 船体坐标系：`x` 向右、`y` 向前、`z` 向上。
- 参考安装：PCB 板面竖直，天线波束中心水平朝前。
- 天线相位中心高度默认 1 m。
- 固定向下安装俯角扫描：0°、3°、5°、8°、10°。
- 平面海面极坐标网格。
- 距离、方位、俯仰和物理掠射角真值。
- 以 TI 公布的 3 dB/6 dB 波束宽度拟合的近似一程方向图。
- 单位 `sigma0`、双程方向图和 `R^-4` 距离扩散下的相对功率。
- 解析实际 AWR2944P CFG，并把载频、斜率、采样率、ADC 样点数、TX 顺序和帧参数写入 HDF5；这些参数在 V0.1 只用于可追溯记录，尚不驱动波形回波。
- MATLAB/Python 共用 HDF5 数据契约。
- Python 静态图和指标摘要。

不包含：

- 动态波浪或海谱。
- APL/GIT/NRL 等绝对海杂波模型。
- 复数 ADC、Range-Doppler、AoA、CFAR 或点云估计。
- 船速、IMU 时间序列和姿态补偿。
- 雷达、云台、电机或 GPIO 控制。

## 深模块与接口

Python `simulation.v01` 模块提供小接口：

```python
config = load_config(path)
result = simulate_flat_sea(
    config.settings,
    mounting_pitch_deg,
    radar_metadata=config.radar_metadata,
)
write_hdf5(result, output_path)
summaries = run_sweep(config, render_plots=True)
```

`SimulationSettings` 封装网格、安装和天线参数；`SimulationResult` 封装真值、方向图和相对功率。调用者不需要了解旋转矩阵、极坐标网格面积或双程增益实现。

MATLAB `run_v01.m` 是同一 HDF5 seam 的独立 adapter。文件根属性 `producer` 标识 `python` 或 `matlab`，Python 读取器负责处理 MATLAB 二维数组的存储维度顺序。Python 可视化只依赖 HDF5 契约，不依赖数据由 MATLAB 还是 Python 生成。

## 方向图假设

V0.1 使用近似方向图，不把它称为实测阵列方向图：

- 方位：0° 为 0 dB，±30° 为 -3 dB，±45° 为 -6 dB。
- 俯仰：0° 为 0 dB，±3° 为 -3 dB，±5° 为 -6 dB。
- 超过 6 dB 半宽后线性下降到配置的增益地板。
- 发射和接收使用相同方向图，因此功率链路使用双程增益。

## 验收行为

1. 高度 1 m 时，向下 3°、5°、10° 的水平海面交点分别约为 19.08 m、11.43 m、5.67 m。
2. 安装向下 5°、俯仰 3 dB 范围 ±3° 时，中心方位强照射区约为 7.12 m 至 28.64 m。
3. 对称海面和对称方向图产生左右对称结果。
4. 波束中心海面单元的方向图损耗约为 0 dB；3 dB 边缘约为 -3 dB。
5. 相同面积和方向图增益下，单位 `sigma0` 功率按 `R^-4` 下降。
6. HDF5 文件可由 Python 读取，并区分 `/truth` 与 `/processed`。
7. 固定输入产生确定性输出；V0.1 不引入随机海面。
8. 3 dB 和 6 dB 的近、远海面交点都写入摘要并显示在覆盖图中。
9. 实际 CFG 的 656 个 ADC 样点、77 GHz 起始频率和 `1/4/8/2` TX 顺序写入 HDF5 `/radar`，但不影响 V0.1 几何与功率结果。

## 手动运行

MATLAB 图形界面运行 `simulation/matlab/run_v01.m` 生成 HDF5；Python 命令读取 HDF5 并生成三维功率图、方位俯仰热图和俯角扫描摘要。MATLAB 批处理启动问题不阻塞图形界面的第一次验收，但在自动批量扫描前必须修复或改用 MATLAB Engine。
