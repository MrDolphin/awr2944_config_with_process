# V0.3.6 海况速度谱统计记录

本阶段固定 256 Chirp、seed=101、散射点抽样、距离权重和 FMCW 参数，仅改变 Hs。
Range-Doppler 功率沿距离维求和，计算速度质心、功率加权 RMS、3 dB 速度宽度和近/远距离功率比。

| 工况 | Hs | 峰值速度 | 速度质心 | 速度 RMS | 3 dB 宽度 | 近/远功率比 |
|---|---:|---:|---:|---:|---:|---:|
| ss2_normal | 0.30 m | 0 | 0.000669 | 0.044577 | 0 | 29.46 dB |
| ss3_nominal | 0.85 m | -0.076043 | -0.025572 | 0.081617 | 0.228129 | 24.21 dB |
| ss3_upper | 1.00 m | 0 | -0.032423 | 0.077498 | 0.228129 | 26.10 dB |

从 0.30 m 到 0.85/1.00 m，速度 RMS 明显增大，3 dB 速度宽度从 0 增加到约 0.228 m/s，
可作为“海况升高后速度维杂波候选展宽”的仿真证据。近/远功率比仍受当前 `1/R²` 权重主导。

边界：这些速度是固定网格 Eulerian 斜距变化率的统计，不是水质点三维轨道速度、绝对 RCS
或实测海杂波谱；非相干散射相位、真实散射系数和 DCA1000 IQ 校准仍未加入。
