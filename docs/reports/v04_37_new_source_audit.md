# V0.4.37 新增 PCB/CAD 资料分析报告

## 1. 目标

分析用户新增的 `sprr440a (1)` 和 `sprr441a` 资料包，确认哪些文件可以为 AWR2944P 海杂波、阵列 AoA 和安装姿态仿真提供输入。

## 2. 资料包差异

`sprr440a (1)` 偏向发布资料：STEP 三维板、装配图、BOM 和 PDF 原理图；适合机械尺寸、器件高度、连接关系和装配证据。

`sprr441a` 偏向 Altium 工程资料：ASCII PcbDoc、工程 PcbDoc、SchDoc、OutJob、层叠 PDF；适合板框、层叠、网络、焊盘、走线和 RF 区域的程序化提取。

## 3. 程序化审计结果

结果目录：`simulation/hardware/awr2944pev/v04_37_new_source_audit/`

关键结果：

- 734 个 Component、514 个 Net、2407 个 Pad；
- 63758 个 Track、1913 个 Via、21 个有效层叠记录；
- `Antenna` Class 明确包含 TX1–TX4、RX1–RX4；
- TX1–TX4、RX1–RX4 作为 8 条单端 RF 网络存在；
- 板框原点为 `(3337.6697 mil, 2034.0003 mil)`，板框尺寸约 `85 mm × 125 mm`；
- 资料审计不改变已有结论：相位中心和安装姿态仍未确认。

## 4. 对当前仿真的直接意义

当前可以增加第三种阵列模型：

```text
理想半波长阵列
    vs
CFG antGeometryCfg 候选模型
    vs
PCB RF 铜区质心候选模型
```

比较指标应包括方位/俯仰偏差、RMSE、旁瓣峰值、角度扫描中的空间混叠和对校准误差的敏感性。PCB 候选模型只能作为“板级几何敏感性”结果，不能直接替代真实天线相位中心。

## 5. 需要继续补齐的证据

1. 从装配图和 STEP 建立板面法向、安装孔和雷达坐标外参；
2. 从原理图/网络连通性建立 TX/RX 到芯片通道的映射；
3. 取得 TI 官方天线封装/阵元相位中心或近场/远场方向图；
4. 通过已知角度目标和 `DCA1000` 原始 ADC 数据实测校准矩阵；
5. 再冻结真实 AoA 阵列模型，并把它接入海杂波点云仿真。

## 结论

本阶段不是“已经获得真实阵元坐标”，而是把资料从“只有 PDF 证据”推进到“有可解析 PCB 工程、RF 网络分组、层叠和板级坐标候选”。这足以开始候选阵列对比和误差预算，但真实 AoA 结论仍需要相位中心、安装外参和实测校准共同支撑。
