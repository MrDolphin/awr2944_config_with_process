# V0.4.38 PCB 候选阵列 AoA 对比

## 目标

将已有 PCB RF 区域几何中心生成的 16 个 TX/RX 虚拟通道，接入 AoA 扫描，与理想半波长阵列和 `.cfg` 的 `antGeometryCfg` 候选进行同一角度网格对比。

## 输入模型

| 模型 | 来源 | 证据状态 |
|---|---|---|
| `ideal_half_lambda` | 软件理想 4×4 半波长虚拟阵列 | 算法基线 |
| `cfg_candidate` | `antgeometry_mapping.csv`，由当前 CFG 的行列和间距展开 | 配置候选，不等于实测相位中心 |
| `pcb_centroid_candidate` | `pcb_antenna_regions.csv` 的 TX/RX 铜区质心求和 | CAD 几何候选，不等于电气相位中心 |

## 扫描设置

- 方位角：`-60°:20°:60°`；
- 俯仰角：`-20°:10°:20°`；
- 斜距：30 m；
- 径向速度：0 m/s；
- 无噪声、无海杂波、无幅相校准误差；
- AoA 算法：当前 V0.4 的相位平面拟合和轴向 unwrap。

## 如何查看结果

结果目录：`simulation/hardware/awr2944pev/v04_38_pcb_array_comparison/`

- `model_coordinates.csv`：三种模型的 16 个虚拟通道坐标；
- `pairwise_metrics.csv`：每种“实际几何—估计几何”组合的 RMSE 和最大误差；
- `pairwise_errors.csv`：每个方位/俯仰网格点的估计值和误差；
- `summary.json`：机器可读摘要；
- `output_analysis.md`：本阶段边界和解释。

阅读 `pairwise_metrics.csv` 时，首先看对角线的“同模型—同模型”结果，再看不同模型之间的交叉结果。理想阵列自匹配接近 0° 是算法基线；交叉 RMSE 大，表示两种坐标语义不能直接互换。

## 主要观察

1. 理想模型自匹配接近 0°，说明基础 IQ 生成和相位拟合链路在规则阵列上通过了回归。
2. CFG 候选与理想模型的结果出现明显误差，说明当前 CFG 的行/列、方位/俯仰间距语义不能直接当成理想半波长网格。
3. PCB 铜区候选的虚拟坐标跨度达到多个波长，广角时会产生相位折叠和空间混叠。
4. PCB 候选即使与自身匹配，在当前简单 unwrap 算法下也可能有非零 RMSE。这是稀疏/非规则阵列求解器尚未实现的信号，不应解读为 PCB 坐标错误。

## 工程结论

本阶段已经把 PCB 资料从“离线审计结果”推进成可运行的阵列敏感性模型，能够用于回答：PCB 几何偏离规则阵列后，AoA 误差和空间混叠风险会如何变化。

但它还不能回答“真实 AWR2944P 的 AoA 精度是多少”。要回答后者，必须继续补齐：天线电气相位中心、芯片通道与 PCB 网络的最终映射、安装姿态外参、实测校准矩阵、适用于稀疏非规则阵列的相位歧义求解器，以及 DCA1000 原始 ADC 已知角度数据验证。
