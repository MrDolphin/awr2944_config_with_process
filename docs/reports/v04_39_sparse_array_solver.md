# V0.4.39 稀疏阵列导向矢量 AoA 求解

## 目标

V0.4.38 发现 PCB 候选阵列的虚拟通道间距达到多个波长，固定轴相位 unwrap 在广角时会出现明显空间混叠。本阶段改用逐角度导向矢量匹配，检查这种误差是 unwrap 限制还是阵列几何本身的角度歧义。

## 方法

对每一个候选方位/俯仰角生成阵列导向矢量，与 16 路复数通道做归一化相关性匹配，并消除未知整体复幅度。扫描网格为方位 `-60°:1°:60°`、俯仰 `-20°:1°:20°`；真值测试点仍为方位 `-60°:20°:60°`、俯仰 `-20°:10°:20°`。

结果目录：`simulation/hardware/awr2944pev/v04_39_sparse_array_solver/`

- `sparse_pairwise_metrics.csv`：各实际/估计几何组合的 RMSE；
- `sparse_pairwise_errors.csv`：每个测试点的估计角度、相关性分数和误差；
- `summary.json`：求解器配置和摘要；
- `output_analysis.md`：机器可读结论。

## 关键结果

三种模型在“实际模型 = 估计模型”时都得到 0° RMSE：

```text
ideal_half_lambda       → ideal_half_lambda       0°
cfg_candidate           → cfg_candidate           0°
pcb_centroid_candidate  → pcb_centroid_candidate  0°
```

这说明导向矢量网格搜索能够正确处理当前三种合成几何模型，V0.4.38 的约 30° 自匹配误差主要来自固定轴 unwrap，而不是当前几何数据无法被建模。

不同模型之间仍然存在大误差。例如理想阵列和 PCB 候选互换时，综合 RMSE 约 33°；CFG 候选和 PCB 候选互换时，综合 RMSE 约 47°。这说明“估计器模型不匹配”会导致严重 AoA 偏差。

## 对项目的意义

当前已经形成两级验证：

1. V0.4.38：固定轴 phase-plane estimator，暴露规则阵列假设和 unwrap 限制；
2. V0.4.39：稀疏阵列导向矢量网格匹配，证明三种候选几何在模型一致时可被正确恢复。

因此，后续将海杂波点云接入 AoA 时，应把“阵列几何模型”和“求解器模型”作为两个独立输入，不能只切换 `.cfg` 或只替换坐标文件。

## 限制

本阶段仍然使用无噪声合成 IQ。PCB 坐标仍是 RF 铜区质心候选，不是电气相位中心；没有加入方向图、互耦、幅相校准、温漂、船体散射或海杂波。导向矢量搜索结果不能作为真实 AWR2944P AoA 精度，也不能替代 TI SDK 和 DCA1000 已知角度实测。

下一阶段应加入：实测校准矩阵、噪声/海杂波、候选峰数量和峰间隔统计，并验证已知角度 DCA1000 原始 ADC 数据。
