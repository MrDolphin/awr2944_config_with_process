# V0.4.42 海面微元法向、速度和 Doppler 代理

## 目标

把 V0.2 动态海面高度场推进为可用于复数海杂波回波的微元属性：海面法向、垂向速度、径向速度、双程 Doppler 和前向散射可见性代理。

## 推导关系

对海面 `z=f(x,y,t)`：

```text
法向 n ∝ (-∂z/∂x, -∂z/∂y, 1)
垂向速度 vz = [z(t)-z(t-Δt)]/Δt
径向速度 vr = vz · LOS_z
双程 Doppler fd = 2·vr/λ
散射代理 ∝ max(n·LOS,0)^2 / R^2
```

当前 V0.2 的空间采样为 `x=-50:1:50 m`、`y=2:1:100 m`，时间步长为 `0.5 s`；雷达安装高度按资料为 1 m。

## 图文/数据分析方式

1. 先看 `case_summary.csv` 的 RMS 径向速度和 Doppler 范围，判断海况运动是否进入复数回波的速度维度；
2. 再看 `microfacet_attributes.csv` 的 `normal_*`、`incidence_cos` 和 `scatter_proxy`，判断哪些微元被前向照射、哪些微元反射权重较高；
3. 最后看 `microfacet_frames.csv` 的主次峰差和跳峰率，判断海杂波是否会造成角度竞争峰和帧间不稳定；
4. 比较海况时不能只看波高，必须同时看风速、波面时间差分、径向速度和散射代理。

## 当前结论

在当前高度场推导模型中，海况从 `ss1` 到 `ss3` 时，RMS 径向速度和 Doppler 展宽总体增加，说明波面运动可以进入速度/频移维度；但跳峰率在所有海况都很高，说明当前结果仍主要受多微元相干叠加、PCB 候选阵列空间混叠和随机校准误差影响。

## 边界

V0.2 没有实测速度、海面散射系数、极化、水平流速或雷达复数 IQ，因此本阶段的速度、Doppler 和散射都是从高度场推导的物理代理。它不能替代真实海杂波模型，也不能作为 AWR2944P 实测性能结论。下一阶段需要把这些微元属性接入 V0.3 距离-多普勒复数回波，加入水平速度、散射谱和海面遮挡。
