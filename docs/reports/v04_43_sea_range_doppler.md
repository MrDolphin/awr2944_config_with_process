# V0.4.43 合成海杂波距离-多普勒复数回波

## 目标

将 V0.4.42 的海面微元属性接入 4×4 虚拟通道复数 IQ，进行距离-多普勒 FFT，并在每个海面帧的峰值单元上运行稀疏阵列 AoA。

## 回波模型

每个微元贡献：

```text
幅度 = sqrt(scatter_proxy)
快时间相位 = 2π · beat_frequency · fast_time
慢时间相位 = 2π · Doppler · slow_time
空间相位 = 16 路 TX/RX 候选阵列导向矢量
```

配置：

- 77 GHz；
- 1 GHz 扫频带宽；
- 128 个 ADC 采样；
- 64 个 chirp；
- PRI = 100 μs；
- 距离分辨率约 0.149896 m；
- 速度分辨率约 0.304173 m/s。

## 如何分析图和数据

1. 查看每个海况的 `*_range_doppler.h5` 中 `/range_doppler/power_linear`，横轴用 `/axes/range_m`，纵轴用 `/axes/velocity_mps`；
2. 看主峰沿速度轴是否展宽或漂移，判断海面运动是否进入 Doppler 维度；
3. 结合 `peak_frames.csv` 的 `range_m`、`velocity_mps`、`estimated_azimuth_deg` 和 `estimated_elevation_deg`，观察距离、速度和角度是否同时跳变；
4. 用 `case_summary.csv` 比较海况时，不能只比较峰值功率，还要同时看速度标准差、峰值距离和 AoA 相关性。

## 当前结果的解释

低海况的峰值速度落在 0 m/s 主要是因为当前速度分辨率约 0.304 m/s，大多数合成微元 Doppler 小于一个速度 bin；这不是说明海面完全没有运动。`ss3_nominal` 和 `ss3_upper` 出现非零峰值速度和更大的速度标准差，说明更强的高度时间变化开始进入距离-多普勒输出。

峰值距离集中在约 3.4–3.5 m，是当前 `1/R²` 散射代理使近距离微元占主导的结果，不能当作雷达真实海杂波最小探测距离或盲区结论。

## 边界

这是由 V0.2 高度场推导微元属性后生成的合成复数 IQ，不是 DCA1000 或 AWR2944P 实测 ADC。当前还没有真实海面 RCS、水平流速、极化、方向图、互耦、船体遮挡或实测校准矩阵。输出可以作为后续 CA-CFAR 和三维点云链路的输入，但不能作为实板性能指标。
