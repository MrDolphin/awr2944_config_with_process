# V0.4.45 CA-CFAR 参数扫描

## 目的

V0.4.44 使用 `Pfa=1e-3`、4×4 训练单元和 1×1 保护单元时，低海况没有输出点。为了区分“海况/散射模型导致没有峰”与“CFAR 门限导致没有点”，本阶段固定同一批 V0.4.43 距离-多普勒功率谱，只扫描 CFAR 参数。

## 扫描矩阵

```text
Pfa: 1e-2 / 1e-3 / 1e-4
训练单元: 2×2 / 4×4 / 8×8
保护单元: 1×1（训练 8×8 时为 2×2）
```

共 9 个 CFAR 场景，覆盖 5 个海况，每个海况 41 帧。

## 关键结果

低海况 `ss0_flat`、`ss1_rippled`、`ss2_normal` 在所有扫描组合下仍为 0 点，说明当前零检测不只是 `Pfa=1e-3` 造成的；更可能与合成散射权重、近距离位置、局部峰值结构和当前噪声底有关。

高海况对 CFAR 参数有明显敏感性：

| 海况 | CFAR 场景 | 检测点数 | 点/帧 |
|---|---|---:|---:|
| `ss3_nominal` | `Pfa=1e-2, train=2×2` | 5 | 0.122 |
| `ss3_nominal` | `Pfa=1e-3, train=2×2` | 4 | 0.098 |
| `ss3_nominal` | `Pfa=1e-4, train=4×4` | 0 | 0.000 |
| `ss3_upper` | `Pfa=1e-2, train=2×2` | 11 | 0.268 |
| `ss3_upper` | `Pfa=1e-3, train=2×2` | 6 | 0.146 |
| `ss3_upper` | `Pfa=1e-3, train=4×4` | 2 | 0.049 |

这说明高海况下确实有可过门限的局部峰，但点云密度会被 Pfa 和训练窗显著改变。

## 如何分析

1. 先固定海况，横向比较 9 个 CFAR 场景；
2. 再固定 CFAR 场景，纵向比较五个海况；
3. 同时查看 `point_count`、`points_per_frame`、平均功率、平均距离和平均速度；
4. 如果只改变 Pfa 就导致点数大幅变化，说明输出点云受 CFAR 参数主导；
5. 如果所有参数都没有点，则要回到散射权重、近距离范围、噪声底和回波建模检查。

## 工程结论

当前不能用 V0.4.44 的“低海况零点”直接推导雷达探测结论。V0.4.45 证明：高海况点云数量对 CFAR 参数敏感，而低海况零点在当前扫描范围内仍然存在。因此下一步应先校准合成回波的噪声底和散射权重，再冻结 CFAR 参数，之后才有意义比较海况对虚警点密度的影响。

## 边界

输入为合成海杂波功率谱，不是 DCA1000 实测 IQ；CA-CFAR 实现是项目分析版本，不是 TI SDK 默认实现；结果不能作为真实虚警率、探测距离或海况性能指标。
