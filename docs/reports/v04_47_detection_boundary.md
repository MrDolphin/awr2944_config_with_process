# V0.4.47 目标检测边界扫描

## 汇报结论

本阶段把 V0.4.46 的单点目标回归扩展为目标 SNR、距离、径向速度、方位和俯仰的边界扫描。输入仍是 V0.4.43 的合成复数海杂波谱，海况选择 `ss2_normal` 和三级海况上限 `ss3_upper`（有效波高目标值 1 m）。

在当前受控注入模型下，最明确的边界来自 SNR：

- `0 dB`、`5 dB`：目标检测概率为 `0`；
- `10 dB`、`15 dB`、`20 dB`：目标检测概率为 `1.0`；
- 这一趋势在 `ss2_normal` 和 `ss3_upper`、`Pfa=10^-2` 和 `10^-3` 下均一致。

因此可以把当前软件链路的初步门限描述为：在本次 CFAR 窗口、合成谱和受控目标注入定义下，目标 SNR 约在 `5~10 dB` 之间出现检测转折。它不是 AWR2944P 的实测灵敏度或最小可检测 SNR。

## 图片/表格如何分析

`detection_boundary_sweep.csv` 是逐扫描点的源数据。汇报时建议画五类图：

1. SNR-检测概率曲线：横轴为目标 SNR，纵轴为检测概率；曲线从 0 跳到 1 的位置就是当前模型的候选检测门限。
2. SNR-虚警点曲线：比较 `Pfa=10^-2` 和 `10^-3`，说明降低 Pfa 是否减少海杂波虚警。
3. 距离-检测概率图：当前结果全部为 1，只能说明“目标单元被直接设置为指定 SNR”；不能解释真实距离衰减。
4. 速度-检测概率图：当前结果全部为 1，尚未建模目标与海杂波 Doppler 谱重叠。
5. 方位/俯仰-AoA RMSE 图：当前受控导向矢量注入时 RMSE 为 0，后续加入幅相误差、校准误差和真实方向图后才有比较意义。

## 海况差异

`ss2_normal` 的虚警点在本次扫描中为 `0/帧`；`ss3_upper` 仍出现海杂波虚警，最大约为：

- `Pfa=10^-2`：`0.268/帧`；
- `Pfa=10^-3`：`0.146/帧`。

目标检测在两种海况均能达到相同的 SNR 转折，是因为目标单元被受控写入；海况差异主要体现在目标之外的海杂波虚警点。

## 必须说明的模型边界

本阶段不能得出以下结论：

- 不能把 `10 dB` 当作 AWR2944P 的真实探测门限；
- 不能据此给出 20 m、40 m、80 m 的真实探测距离；
- 不能据此判断 0 m/s、1 m/s、6 m/s 目标速度的真实可检测性；
- 不能把 0° AoA RMSE 当作实测角度精度。

原因是当前目标注入没有加入目标 RCS、雷达方程距离衰减、天线方向图增益、目标 Doppler 展宽、目标与海杂波谱重叠、真实通道幅相误差和 TI 校准矩阵。因此距离/速度/角度扫描当前主要验证了参数传递和输出统计接口，而非真实物理边界。

## 下一步建议

V0.4.48 应把目标模型从“单个距离-Doppler 单元受控写入”升级为：

1. 按目标 RCS 和双程距离衰减生成幅度；
2. 按目标速度生成 Doppler 相位随帧/慢时间变化；
3. 按目标距离和速度生成主瓣及旁瓣扩展，而不是单点替换；
4. 叠加 PCB 阵列方向图和已知幅相误差；
5. 再重复本阶段的 SNR、距离、速度、方位和俯仰扫描。

这样得到的检测边界才具有论文和海试参数设计价值。
