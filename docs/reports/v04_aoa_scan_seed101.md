# V0.4.1 AoA FOV 扫描记录

扫描范围对应配置参考 `aoaFovCfg -1 -60 60 -20 20`：方位 -60°～60°、俯仰 -20°～20°，
共 35 个角度点。加入噪声标准差 0.02 和通道相位误差标准差 1°，随机种子 101。

初始合成 TX 间距为 1 个波长，扫描发现方位 RMSE 约 50°，原因是空间混叠/栅瓣；修正为
TX/RX 半波长间距后，方位 RMSE 降至 0.166°，最大方位误差 0.450°，俯仰 RMSE 0.109°，
最大俯仰误差 0.328°。

这说明阵元间距是 AoA FOV 的关键设计约束：`±60°` 的配置范围不能单独保证角度可用，
还要满足阵元间距、真实天线方向图、通道校准和噪声条件。当前阵列仍是软件合成布局，
不代表 AWR2944P EVM 实测 AoA 精度。

实际结果目录：`simulation/stages/v04_aoa_cfar_point_cloud/results/python/v04b_aoa_scan_seed101_v2/`。
