# V0.4.13 PCB 坐标变换 AoA 筛查

## 目的

V0.4.12 发现 PCB 坐标的 Y 方向与 CFG row 定义可能存在交换或镜像。本阶段不直接修改 CFG，而是分别用四种解释生成相位，再用 `antGeometryCfg` 展开的 CFG 阵列坐标估计角度：

```text
raw / X 镜像 / Y 镜像 / 180° 旋转
```

## 重要区别

这里的相位由 PCB 坐标生成，AoA 估计使用 CFG 理想阵列。因此，结果可以反映坐标模型不一致；不能再把“同一坐标生成、同一坐标估计”的自洽结果当成精度证明。

## 输出

逐变换指标见：

`simulation/stages/v04_aoa_cfar_point_cloud/output/v04_13_coordinate_transform_scan/transform_scan.csv`

汇总见同目录 `summary.json` 和 `output_analysis.md`。

本次使用 CFG 展开的 16 通道坐标后，raw 变换的方位/俯仰 RMSE 为 38.2415°/21.8899°；Y 镜像为 38.2415°/22.4927°；X 镜像为 42.8077°/21.8899°；180° 旋转为 42.8077°/22.4927°。这说明四种简单刚体变换都没有把 PCB 铜区近似变成可信的 EVM 阵列模型，不能仅凭筛查结果选择 Y 镜像。

## 结论边界

综合 RMSE 最小的变换只能作为坐标解释候选，不能证明它就是 EVM 的真实板面朝向。最终选择必须有装配图方向、PCB 原点/层面定义、天线馈电点或角反射器实测支持。
