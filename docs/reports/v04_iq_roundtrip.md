# V0.4.9 DCA1000/TDM/AoA 合成闭环

使用已知方位 20°、俯仰 10° 的合成角反射器，按当前 4TX TDM 顺序打包为 int16 I/Q，再经过：

```text
编码 → DCA1000 解码 → TX1/TX2/TX3/TX4 重排 → AoA
```

结果：

| 项目 | 结果 |
|---|---:|
| 原始字节数 | 65536 |
| 解码形状 | (64, 64, 4) |
| 虚拟通道形状 | (16, 64, 4, 4) |
| 方位角误差 | 0.006076° |
| 俯仰角误差 | 0.004310° |

误差主要来自 int16 量化。该结果证明软件数据格式和 TDM 维度闭环一致，但只使用合成数据，
不能证明真实 DCA1000 的 LVDS lane 拼接、I/Q 符号、RX 通道编号、TX 归属或硬件校准。
