# V0.4.17 PCB 走线相位敏感性分析

## 目的

把 V0.4.15 的 TX/RX 几何路径长度与 V0.4.16 的层叠候选参数连接起来，观察走线相对电长度变化对 AoA 的敏感程度。

## 模型

对每个虚拟通道使用：

```text
Δφ = 2π / λ × (sqrt(ε_eff) - 1) × (L_TX + L_RX)
```

并减去全部通道的平均相位，只保留会影响 AoA 的相对相位。测试 `ε_eff = 1、2.5、3.0、4.04`。

## 边界

这里的 ε_eff 不是从 PCB 截面求解得到的有效介电常数；几何路径也没有包含完整过孔、弯折、阻抗过渡和天线馈电。结果只能作为相位误差敏感性筛查，不能作为真实 EVM 校准或 AoA 精度结论。

输出目录：`simulation/stages/v04_aoa_cfar_point_cloud/output/v04_17_phase_sensitivity/`。

## 当前输出解读

在当前 PCB 几何中心和 CFG 坐标模型下，`ε_eff=1` 时方位/俯仰 RMSE 已为 38.3208°/22.6125°；`ε_eff=2.5`、3.0、4.04 时分别为 38.2304°/24.2855°、38.2241°/24.2895°、38.0000°/23.6879°。这说明当前主要误差仍来自阵列坐标/相位中心模型不一致，不能把 ε_eff 扫描造成的微小变化解释成校准改善。
