# 固定零位逐圈统计：第一阶段（离线核心）

2026-11-08。本阶段仅新增 `scan_revolutions.analyze_revolutions` 与测试，不改变网页、硬件配置、在线配准或原始采集。

## 口径

- 输入：按原始记录顺序提供 `live_registration.jsonl` 事件。只把 `status=registered` 的 `yaw_deg` 作为角度样本。`direction` 必须是该 yaw 字段的实测递增/递减趋势，不能直接照填电机 CW/CCW。
- 固定零位：`zero_deg` 在输入 yaw 坐标系下定义，默认 0。每次通过零位时分圈；首尾残圈保留。起始恰在零位可作为起始边界，边界样本只属于后圈，不重复计数。
- `complete` 仅表示起止零位边界被连续观测包围，**不表示方位覆盖完整、无丢帧或 RF 时间已经校准**。
- 每圈输出有效配准事件数、唯一方位数、最大圆周角度间隔、首尾帧号、时间范围及零位边界时间包围区间。不插值生成新方位线，不估造精确过零时刻。
- `valid_lines` 目前是配准事件数，**尚未与 frames.jsonl/TLV2 是否存在做关联**，不能当成最终有效 TLV2 数。
- 配准拒绝按整次记录累计原因，缺角度的拒绝事件不强行归入某个角度/圈。`raw_missing_frames=null` 明确表示未检查原始帧号，不能把配准帧号跳变直接当串口丢帧。
- 时间不递增、帧号重启、配准参数变化、超时、角度跨度超限、反向或角度回绕歧义会切断连续段。32 位帧号正常回绕不是重启。
- 默认离线门限：间隔 0.1 s、角度步长 10°、可能最高转速 130 rpm。若时间间隔允许转过 180°，不猜回绕方向。参数仅用于离线诊断，不改变电机限速/安全设置。
