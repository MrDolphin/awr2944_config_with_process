# TLV2 PPI 有界扇形显示验证

## 目的与证据边界

将固定 2 像素射线改为“距离格 × 方位角”的环形扇区。相同角宽在远处自然更宽；每格仍使用原始方位线对应距离格的强度映射，不插值制造回波。
这是显示优化，不等于新增方位采样、改善角度分辨率或实现 MAS10 的硬件性能。没有修改 CFG、串口、记录器、配准拒绝阈值或电机控制。

## 方位单元规则

- 从保留样本的采集顺序估计相邻角增量的中位数，支持跨 0° 和正反转。
- 正常相邻方位在中点分界；大于典型间隔 1.5 倍时，两侧仅延伸半个典型间隔，中间保留缺口。
- 显示单元最大角宽 6°；这是保守显示上限，不是天线波束宽度。单个样本无间隔依据时采用 0.9°，不铺满全圆。
- 同角度重复样本使用最近收到的一条；不同角度的历史样本仍受原有滚动缓存生命周期约束。
- 米制距离轴使用距离格宽，盲区继续遮罩。强度低于显示抑制门限仍可显示为黑色，所以仅凭黑色不能判断缺测；本轮尚未新增逐圈覆盖诊断。

例：200 条均匀采样对应 1.8° 单元，400 条对应 0.9°；正常区域可相接。典型间隔 1.8° 时出现 10.8° 间隔，仅两端各延伸 0.9°，留下 9° 缺口。

## 下次现场验收

1. 刷新实际打开的 fusion 工作树 `radar_app.html`，切换“TLV2 强度 PPI”；状态应含“有界扇形”，悬停查看边界说明。
2. 保持原先已验证的转速、CFG、盲区和对比度参数不变。确认正常采样区域呈小扇形栅格，外圈横向宽于内圈，近场盲区仍为黑色。
3. 观察真实缺测区域仍留白；不能因为本次显示更连续，就宣称丢帧或配准拒绝已解决。
4. 同一份采集回放对照原始强度与背景扣除。弱回波是否被抑制与有没有方位样本是两回事。
5. 检查持续刷新、浏览器流畅度与记录告警。逐圈有效线数、最大缺口、拒绝原因、时间配准仍为后续独立验收项。
