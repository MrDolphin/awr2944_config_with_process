## 边界

本阶段已加入距离相对衰减、RCS参数和局部距离-Doppler扩展，但仍不是绝对功率标定模型，也未加入真实目标RCS测量、天线增益、系统损耗、噪声系数、目标微动和实测IQ。因此检测概率用于模型趋势和接口验证，不作为实测探测距离结论。
