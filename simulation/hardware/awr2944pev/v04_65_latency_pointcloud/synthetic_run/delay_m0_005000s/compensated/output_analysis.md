## 如何解释

固定姿态结果把所有帧都按同一个安装姿态投影；补偿结果按对应 frame 的 IMU RPY 旋转。两者之差表示船体姿态变化对点云坐标和角度的影响，不是目标真实运动，也不是雷达 AoA 算法误差。

## 证据边界

本次 IMU 文件和点云均为合成/历史仿真输入，不能作为船上实测姿态补偿性能。接入真实 IMU 时必须确认时间戳同步、坐标轴方向、角度单位和初始安装外参。
