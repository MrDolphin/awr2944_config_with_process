# V0.3 复数回波与 Range-Doppler 输出分析规范

每一个 V0.3 运行目录都必须保存 `output_analysis.md`。该文件至少说明：

1. 引用的 V0.2 truth run、case、网格索引和全部 FMCW 参数；
2. HDF5 IQ、Range-Doppler 矩阵和坐标轴的维度及单位；
3. 图像横轴、纵轴、颜色和峰值标记分别表示什么；
4. 峰值距离/速度与 V0.2 斜距/斜距变化率的误差；
5. 分辨率、混叠和窗函数对图像的影响；
6. 可以得出的工程结论与不能得出的结论；
7. 下一阶段的输入和验收门槛。

## 图像分析顺序

对于 `figures/range_doppler.png`，先确认距离峰是否位于 V0.2 真值斜距附近，再确认速度峰是否在理论径向速度附近。若速度小于一个 Doppler bin，峰落在 0 m/s 不视为失败；若距离误差超过一个距离分辨率，应先检查 beat-frequency、采样率、chirp slope 和 HDF5 单位。

V0.3.1 是单散射微元回归，不是海杂波功率或目标检测结论。只有 V0.3.2 多微元叠加后，才分析距离展宽、速度展宽和海况差异。
